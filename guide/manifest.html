json
{
  "manifest": {
    "id": "example.buds",
    "displayName": "Example Buds",
    "version": "1.0.0",
    "schemaVersion": 5,
    "runtimeApi": 1,
    "requires": [],
    "matchers": [
      {
        "type": "namePrefix",
        "value": "Example Buds"
      }
    ]
  },
  "protocol": {},
  "states": {},
  "actions": {},
  "triggers": {},
  "ui": {
    "children": []
  }

必填字段 ​

字段规则
id与 package.json.id 完全一致
displayName非空
version与 package.json.version 完全一致
schemaVersion新包写 5
matchers至少一条

可选字段包括 runtimeApi、capabilities、requires、extensions、author、description、homepage、deviceType、minRuntime 和 runtime。未知字段不应被当作扩展机制使用。

设备匹配器 ​

type主要字段说明
nameExactvalue名称完全相同
namePrefixvalue名称前缀
nameRegexvalue名称正则
addressRegexvalueMAC 地址正则
serviceUuidvalue广播中的服务 UUID
manufacturerDatacompanyId、可选 prefix广播厂商数据

匹配器可带整数 priority，数值越大越优先。

json
{
  "matchers": [
    {
      "type": "manufacturerData",
      "companyId": 89,
      "prefix": "A5 5A",
      "priority": 300
    },
    {
      "type": "namePrefix",
      "value": "Example",
      "priority": 100
    }
  ]
}

至少保证有一条规则能命中目标设备。名称规则便于调试，广播数据规则通常更稳定。

声明所需能力 ​

requires 是加载期能力声明，已经由宿主实现，不是下载依赖，也不授权包内执行代码。

常用名称：

类别名称
校验checksum.none、checksum.sum8、checksum.xor8、checksum.crc
拆帧splitter.delimited、splitter.lengthPrefixed
组帧framing.segmented、framing.command24
会话程序session.send、session.request、session.waitFor、session.onFrame
流程session.triggers、session.initializationPolicy
扩展session.extension

只声明实际使用的能力。重复、拼错或当前 runtimeApi 不支持的名称都会使包加载失败。

扩展声明 ​

json
{
  "requires": ["session.extension", "session.request"],
  "extensions": [
    {
      "id": "example.auth",
      "apiVersion": 1,
      "entry": "default"
    }
  ]
}
