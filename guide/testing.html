在仓库根目录执行：

bash
cd BtRemix
./gradlew :app:testDebugUnitTest

powershell
.\BtRemix\gradlew.bat -p BtRemix :app:testDebugUnitTest

SamplePackageTest 会调用真实的 DevicePackageReader 和 DevicePackageValidator 校验 samples/ 下的包。扩展样例还会检查显式注册表。

cd docs/device-package-wiki

安装到设备 ​

最直接的方式是在 BtRemix 的“设备包”页面导入 .dcpkg。

也可以使用 adb：

bash
adb push example.dcpkg /data/local/tmp/example.dcpkg
adb shell "run-as com.Fusion.Btremix mkdir -p files/device-packages"
adb shell "run-as com.Fusion.Btremix cp /data/local/tmp/example.dcpkg files/device-packages/example.buds.dcpkg"
1
2
3

应用 ID 当前为 com.Fusion.Btremix。安装文件名的最后一段应为 <manifest.id>.dcpkg。重新打开应用后包会重新加载。

内置包不能被覆盖或删除。替换已安装包前先提高版本，再确认覆盖。

常见错误 ​

现象常见原因修正
unsupported packageFormat容器版本不是 1改为 "packageFormat": 1
package/manifest ID 不一致两处 ID 不同对齐两个值
package/manifest version 不一致只更新了一处版本对齐两个值
manifest.matchers缺少匹配规则至少增加一条
unsupported capabilityrequires 拼错或不存在只写宿主支持的能力
unknown matcher typematcher 类型拼错核对匹配器表
command must fitcommand 超出布局宽度修正宽度或使用 segmented
matcher 找不到 sequence/payload响应布局缺少相应段增加布局段或删除匹配条件
新旧匹配字段混用同时使用 matcher 和 old fields只保留 v5 matcher
overlaps trigger两个 trigger 可能命中同一帧用 command/prefix/type 明确区分
initialization 要求 JSON programaction 不是 script 动作改用 program 或带 script 的动作
unknown declared extensionmanifest 未声明扩展补 manifest.extensions
unsupported extension组合根未注册实现由第一方显式注册
melody.support.productId值非法或未规范化为十进制写十进制值，或保留合法的 0x 输入让解析器转换
refresh 要求固定 payload回读事务不是常量请求单独定义固定 payload 的读事务
unknown state/actionUI 或程序引用不存在的 ID补齐定义
原生 ANC 点按无效UI 缺少可交互 ANC 状态行使用 segmented/slider/switch
包内资源被拒绝出现可执行文件或未知路径只保留 JSON 和 assets/**

小米设备还需要分别确认 MMA 认证、精确型号 matcher、RCSP 通知方向和电量/ANC 的 command 冲突。参考小米耳机协议。

推荐调试顺序 ​

  1. 先校验容器、ID、版本和 matcher。
  2. 用最小事务确认请求帧的字节布局。
  3. 确认响应 matcher 和 payload 解码。
  4. 再验证 notify、初始化和设备主动请求。
  5. 最后检查 UI 引用与 Melody 投影。

这样可以把“包无法加载”“协议不响应”“状态不更新”和“页面操作无效”分开定位。
