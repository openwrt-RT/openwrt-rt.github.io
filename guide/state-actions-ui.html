状态、动作与界面 ​

协议层完成字节映射后，用 states、actions 和 ui 暴露用户可见能力。

状态 ​

支持 boolean、integer、number、string、enum 和 bytes。

BtRemix 声明的状态可以在 UI 中展示，也可以被初始化流程和 JSON 程序读写。页面和程序引用 ID 时必须真实存在。

enum 状态需要非空 enumValues，默认值必须是其中一个合法字符串。

声明式动作 ​

普通读写优先使用 transaction：

json
{
  "actions": {
    "level.set": {
      "displayName": "Set level",
      "parameters": [
        {
          "name": "level",
          "type": "integer",
          "min": 0,
          "max": 10
        }
      ],
      "transaction": "level.set",
      "arguments": {
        "level": {"arg": "level"}
      },
      "resultState": "level",
      "result": {"arg": "level"}
    }
  }
}

规则：

  • transaction 与 script 互斥；

  • resultState 必须存在于 states；
  • 有 result 时必须有 resultState。

json
{
  "transaction": "anc.set",
  "refresh": ["anc.get"]

Melody 投影 ​

melody 是按需启用的顶层字段，只用于需要投影到宿主 Melody 界面的包。

  • 出现 melody 时必须有 support.name；
  • 当前 mode 只能是 bridge；
  • productId 使用归一化十进制字符串；
  • 桥接设备避免让 Melody 再打开第二条传输；
  • templateWhitelist 只能指向 APK 内置资源。

如果包要使用原生 ANC 控件，ui 中必须保留一行读取 ANC 模式状态的 segmented、slider 或 switch。只有 button 会导致原生控件显示但无法正确响应。

melody.anc 中的 state 和 action 必须引用真实定义，protocolIndex 不能重复，强度级别必须严格递增并落在状态范围内。

Melody 的完整 modeType 映射和宿主行为请查阅仓库中的 docs/melody-capability-map.md 与 docs/MELODY_BRIDGE_SPEC.md。
