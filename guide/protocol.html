选择帧格式 ​

设备情况建议
GATT 简包不写 framing
RFCOMM 单字节头尾codec: "framed"
请求/响应布局不同codec: "segmented"
2 或 3 字节 commandsegmented + framing.command24
length-prefixed、CRCsegmented

需要重点检查：

  • 请求表和响应表各有一个 command、length、payload；
  • 声明 checksum 时，两张表各有一个 checksum；
  • payload.includeInLength 为 true；
  • command 和 length 位于 payload 前；
  • length 不含自身，checksum 不覆盖自身；
  • includeInLength、includeInChecksum 选中的段连续；
  • segmented 不混用 header、trailer、layout 等 framed 字段。

command 宽度只能是 1、2 或 3 字节。使用 2/3 字节时在 requires 中加入 framing.command24。

  • 已声明的条件必须同时成立；
  • 使用 sequence 时，响应布局必须有 sequence 段；
  • 使用 payloadPrefix 时，响应布局必须有 payload 段；
  • 不要同时混用旧字段 expectedPayloadTypes 和 v5 matcher。

两种初始化 ​

旧式初始化适合已有包：

json
{
  "initialize": ["battery.get", "anc.get"]
}
1
2
3

v5 新包优先使用 initialization：

json
{
  "initialization": [
    {
      "required": true,
      "transaction": "battery.get"
    },
    {
      "required": false,
      "program": [
        {
          "op": "state.set",
          "key": "initialized",
          "value": true
        }
      ]
    }
  ]
}
