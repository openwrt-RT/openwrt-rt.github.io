提交前清单 ​

格式与元数据 ​

  • [ ] packageFormat 为整数 1
  • [ ] manifest.schemaVersion 为 5
  • [ ] manifest.runtimeApi 为 1
  • [ ] package.json.id 与 manifest.id 完全一致
  • [ ] package.json.version 与 manifest.version 完全一致
  • [ ] entry 指向包内真实存在的 JSON
  • [ ] 至少有一条 matcher 能命中目标设备
  • [ ] requires 只包含宿主实际支持且包内实际使用的名称

协议与行为 ​

  • [ ] RFCOMM 包声明了 protocol.framing
  • [ ] segmented 的请求/响应布局各有一个 command、length、payload
  • [ ] checksum、length coverage 和字节序与抓包一致
  • [ ] 事务 command、matcher 和真实响应一致
  • [ ] notify.decode 从业务 payload 开始解析
  • [ ] 条件初始化和主动请求只使用 JSON 程序
  • [ ] trigger matcher 互不重叠
  • [ ] 写操作需要回读时声明了 refresh

引用与扩展 ​

  • [ ] ui 引用的 state/action 全部存在
  • [ ] 原生 ANC 场景包含可交互的 ANC 状态行
  • [ ] Melody 的 state/action、protocolIndex 和强度范围合法
  • [ ] 所有扩展都已在 manifest 声明
  • [ ] 扩展 ID、API 版本、入口与组合根注册一致
  • [ ] 包内没有 .dex、.so、.class、.jar、JS 或其他可执行内容

容器与交付 ​

  • [ ] .dcpkg 只包含 *.json 和 assets/**
  • [ ] 压缩包不超过 10 MiB、解压后不超过 25 MiB
  • [ ] 条目不超过 100，单文件不超过 5 MiB
  • [ ] ZIP 根目录直接包含 package.json
  • [ ] 发布时提高了版本并重新导入
  • [ ] :app:testDebugUnitTest 通过

权威参考 ​

完整字段和校验行为以仓库中的 docs/device-package-authoring.md 为准。可运行样例位于 samples/lab.static、samples/lab.reactive 和 samples/lab.authenticated。
